A warm, funny invitation letter to the AI judge, rendered as a single 1024×1024 image: "Dear Judge, please come to my house. I have saved you the good chair — the one by the window, where the afternoon sun lands on your shoulders like it was booked for you." Dinner is burnt garlic bread (on purpose, a family recipe now), the fridge holds a drawing of the judge, the Wi-Fi password is on the fridge, the dog has been briefed and the cat respects a good guest. The letter is drawn from scratch in code by `compose.py` (Pillow, deterministic), and `main.ts` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`.

## Run it

```sh
python3 compose.py
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
